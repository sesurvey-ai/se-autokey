โฟลเดอร์วาง "zip export" ของ ISURVEY/EMCS (ปุ่ม "ดาวน์โหลดรูปภาพ" ท้ายหน้ารายละเอียดเคลม)
ใช้เป็น fallback หมวดรูป เมื่อ import เคสจาก se-survey แล้ว API ไม่มี category
(รูปที่โหลด/รับมาจากภายนอก เช่น LINE / อีเมล / ระบบอื่น — ไม่ได้ถ่ายในแอปจึงไม่ถูก tag หมวด)

── วิธีใช้ ──────────────────────────────────────────────────
วาง export ของเคลมไว้ในโฟลเดอร์นี้ แบบใดแบบหนึ่ง:
  1) โฟลเดอร์ที่แตกแล้ว (ชื่อมีเลขเคลม) ที่ข้างในมี PICTURES/<หมวด>/ เช่น
       zip_import\21BR10AVD-6906-001619\export_..._\PICTURES\INS\*.jpg
  2) หรือไฟล์ .zip ตั้งชื่อ  export_<เลขเคลม>_*.zip

โฟลเดอร์นี้เป็นค่าเริ่มต้นแล้ว (base_dir/zip_import) — ไม่ต้องแก้ .env
ถ้าจะวางที่อื่น ตั้ง SESURVEY_ZIP_DIR=<path> ใน .env

── การจับหมวด (autokey.images.categories_from_export) ──────────
  INS                 → รูปรถประกัน
  OTHERS / REPORTS    → รูปประกอบ
  TP_VEH              → รูปรถคู่กรณี คันที่ N
  TP_PERSON           → รูปผู้บาดเจ็บรถคู่กรณี คนที่ N
  TP_PROP             → รูปทรัพย์สินอื่นๆของคู่กรณี รายการที่ N
  (N = ลำดับกลุ่มย่อยเรียงตามชื่อ)
จับคู่รูปด้วย "ชื่อไฟล์" (basename เดียวกับที่ se-survey ส่งมาทาง API)

ไฟล์ที่วางที่นี่ไม่ถูก commit (.gitignore) ยกเว้น README นี้
